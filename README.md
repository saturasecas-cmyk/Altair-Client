# Altair Launcher (Windows)

Launcher de Minecraft para Altair Client. Elige la versión (1.20.1 a 26.2) y el launcher descarga Java (Temurin), instala Forge con el instalador oficial, baja el mod de las releases de GitHub y lanza el juego. Login con cuenta Microsoft (o modo offline).

Desarrollo: `cd launcher && npm install && npm start`. Build: `npm run dist`.
